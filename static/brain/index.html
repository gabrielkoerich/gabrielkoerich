Two closer looks

The two paths that matter most to an agent: what happens when it asks, and what happens when it writes.

A search

Retrieval is ranking and one small reranking model. Nothing generates text.

  1. Ask An agent, or you, ask in plain words.
  2. Filter by access Access rules apply first, inside the database. A prompt or a tool argument cannot widen them.
  3. Rank four ways, side by side Words in the text. Notes named for the question. Dated notes, when the question names a period such as last week. Passages closest in meaning.
  4. Fuse The lists merge into one ranking, with one hit for each note or session.
  5. Rerank the best A cross-encoder reads the top 20 against the question. If it runs past its time budget, the fused order is returned.
  6. Return the passage The passage that matched, the turns around it and its date. Near-duplicates are dropped and the answer is trimmed to a token budget.

A write

One writer owns every change, so a file and its index never disagree.

  1. Write An agent remembers a note, edits a section, retires a fact or leaves a handoff.
  2. Queue on the agent's machine The write is saved locally and answered at once. If your server is down, it is sent when the server is back.
  3. Redact Secrets are replaced with a marker before the text is stored, indexed or embedded.
  4. Check An edit based on an old version is refused with a conflict. A write that is sent twice is applied once.
  5. Write the file The markdown file is replaced in one step, so a crash never leaves half a note.
  6. Update the index Full text and links commit in one transaction. The passage vectors follow in the background.
  7. Keep the history The files are committed to git every three minutes.

What always holds

The files are the truth
Delete the index and brain rebuilds it from the markdown files, with no loss.
Nothing is overwritten silently
A write based on an old version fails with a conflict. Agents append or patch a section.
Upkeep archives, it never deletes
Only the owner can purge a note, and never through an agent.
Secrets are redacted first
Before anything is stored, split into passages or embedded.
Access is checked in the database
On every query. Personal notes live in a separate database file.
